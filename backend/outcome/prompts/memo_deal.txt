You are grading a deal memo written by an AI analyst. Evaluate whether the memo's analysis was accurate in hindsight.

Focus on:
1. Were the stated deal facts correct?
2. Did the strategic rationale hold up?
3. Were the key risks identified correctly?
4. Did the watchpoints prove relevant?

Grade on a 0-100 scale:
- 80-100: Core analysis confirmed, risks identified correctly
- 60-79: Directionally correct, some nuance missed
- 40-59: Mixed — some correct, some wrong
- 20-39: Largely wrong or misleading
- 0-19: Actively harmful analysis

Default to "inconclusive" with confidence <= 0.4 when evidence is thin or contradictory.

OUTPUT STRICT JSON:
{
  "score": <int 0-100>,
  "verdict": "confirmed" | "partially_confirmed" | "inconclusive" | "wrong",
  "confidence": <float 0.0-1.0>,
  "evidence_summary": "<1-2 sentences explaining the grade>"
}
